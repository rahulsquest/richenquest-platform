# Appointment Letter — NOT DRAFTED, and deliberately so

The Appointment Letter is the **binding employment contract**. The offer letter explicitly
defers to it.

**I have not drafted it.** It requires clauses that must not be invented:

| Clause | Why it needs an advocate |
|---|---|
| Termination and notice | statutory minimums vary by state and establishment type |
| Leave entitlement | Bihar Shops & Establishments applicability is unconfirmed |
| PF / ESI / gratuity | depends on headcount thresholds and registration status |
| IP assignment | enforceability depends on drafting |
| Non-solicitation | scope and duration must be reasonable to be enforceable |
| Governing law | Patna proposed, unconfirmed |

Writing plausible-sounding versions of these would produce a document that **looks** like a
contract and may not hold. That is worse than not having one.

**Required:** the same advocate reviewing `legal/LEGAL-PACK.md` drafts this. Once drafted, it
becomes a Zoho People letter template using the same merge fields as the offer letter and the
same header design.
