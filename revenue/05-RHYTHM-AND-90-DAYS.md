# SECTION 9 · Rahul's Day — maximum 3 hours

## Morning — 60 min (09:00)
- **10 min** Counsellor Dashboard. Only two questions: is anything HIGH untouched, and did
  anyone not get called within 48h?
- **40 min** **Trust-node calls. Five per day, every day.** This is the only activity that
  creates leads from nothing. It is non-negotiable and it does not get rescheduled.
- **10 min** Approve anything customer-facing that is waiting

## Afternoon — 60 min (15:00)
- **30 min** Counselling call or closing call — the founder personally handles the first 10
  students' closing calls
- **20 min** Whatever the current bottleneck is (today: chasing the 4 admissions emails)
- **10 min** Reply to parent messages

## Evening — 30 min (19:00)
- **10 min** Any student message unanswered today → answer it
- **10 min** Tomorrow's 5 node calls: names and numbers written down tonight
- **10 min** Write down today's five numbers: leads, calls, proposals, payments, cash

## Friday — +60 min
- Weekly review (Section 5) · every Friday update sent · one post-mortem · the five numbers
  for the week compared with last week

## Monthly — +120 min
- Books reconciliation · re-verify university data · QA sample · refund reserve ·
  reprioritise the 90-day plan against actuals

**What Rahul does NOT do:** build, redesign, write documentation, research universities that
no live student needs, or open the CRM to admire it.

# SECTION 10 · What AI does automatically, every day, forever

**Already running — no new build**

| When | What | Function |
|---|---|---|
| On submit | Parse, normalise, create Lead, qualify, assign owner, raise 48h call task and passport task, record consent, issue case number | `submitApplication` |
| On submit | Send the student their case number and callback time | WhatsApp template §1 |
| 05:30 daily | Re-plan every open case backwards from its course start; compute the last safe visa filing date | `visaOpsSweep` → `visaOpsPlan` |
| 05:30 daily | Append every state, band and blocker change to the immutable timeline | `recordStateEvent` |
| 06:30 daily | Six sweeps; silent when clear, alerts only on exception | `opsWatch` |
| On open | Assemble the whole student picture and compute the ONE next action with its reasoning | `student360` |
| On open | Rank every actionable task across all modules; hard blocks band HIGH regardless of score | `buildWorkQueue` |
| Continuous | Refuse to progress a case with a hard block: no consent, no passport, timing lost, refusal unrecorded, appointment without documents, deadline passed | `caseState` |
| On write | Coerce every picklist and numeric value to CRM-exact form | `normalizeInput` |

**AI does not, and must not:** call a student, decide a price, promise an outcome, sign
anything, book a visa appointment, or send a customer-facing message that has not been
approved.
